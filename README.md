# Okos Széf Projekt (Arduino)

Ez egy biztonsági széf prototípus, amely 4x4-es billentyűzettel, I2C LCD kijelzővel és szervomotoros zárral működik.

## Funkciók
* PIN kódos azonosítás (Alapértelmezett: 1234)
* Interaktív LCD kijelző visszajelzés
* Automatikus visszazárás 5 másodperc után
* Hibás kód kezelése

## Eszközlista
### Hardver
* Arduino Uno R3
* 4x4 Mátrix Billentyűzet
* I2C LCD Kijelző (16x2)
* SG90 Szervomotor
* Breadboard és Jumper kábelek
* Karton/Fa doboz (burkolat)

### Szoftver
* Arduino IDE
* Könyvtárak: `Keypad.h`, `LiquidCrystal_I2C.h`, `Servo.h`

## Beépítés és Mechanika
A széf egy kartondobozba került beépítésre. A zárást egy szervomotorra rögzített kar (retesz) biztosítja, amely az ajtó fülébe akad bele.
